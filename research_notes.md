# Daily Gmail Export Delivery — Reference Notes

- Google’s App Password guidance states that an App Password is a 16-character passcode and requires 2-Step Verification. It may be unavailable for accounts using security keys only, organization-managed accounts, or Advanced Protection. Source: https://support.google.com/mail/answer/185833?hl=en
- Google Workspace’s SMTP guidance identifies `smtp.gmail.com` as the Gmail SMTP host, with SSL on port 465 or TLS on port 587. It states that full account email plus an App Password are used for authentication. Source: https://knowledge.workspace.google.com/admin/gmail/send-email-from-a-printer-scanner-or-app
